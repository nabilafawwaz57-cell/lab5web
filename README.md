## 🌷 Deskripsi Praktikum

Praktikum 5 membahas dasar-dasar JavaScript dan penerapannya dalam halaman web. JavaScript digunakan untuk menambahkan logika dan interaksi sehingga halaman web tidak hanya menampilkan informasi, tetapi juga dapat memproses input serta merespons tindakan pengguna.

Materi praktikum meliputi penggunaan output, variabel, operator aritmetika, function, percabangan, perulangan, manipulasi Document Object Model (DOM), event, dan validasi form.

Seluruh latihan dikerjakan menggunakan HTML dan JavaScript, kemudian diuji melalui browser Google Chrome.

## 🎯 Tujuan Praktikum

- Memahami sintaks dasar JavaScript.
- Menggunakan output melalui Console, Alert, dan Prompt.
- Memahami penggunaan function dan operator aritmetika.
- Menerapkan percabangan `if-else` dan `switch`.
- Menggunakan perulangan untuk menjalankan instruksi berulang.
- Memanipulasi elemen dan tampilan HTML menggunakan DOM.
- Membuat interaksi melalui tombol, checkbox, dan form.
- Memvalidasi input serta mengolah data dari pengguna.
- Menerapkan materi melalui mini-project sederhana.

## 📝 Penjelasan Setiap Latihan

### 01. Output Hello World

Latihan pertama merupakan pengenalan JavaScript. Program menampilkan teks pada halaman HTML dan Console browser. Latihan ini juga memperkenalkan cara menghubungkan file JavaScript dengan HTML agar kode JavaScript dapat dijalankan ketika halaman dibuka.

### 02. Alert dan Prompt

Latihan ini mempelajari interaksi sederhana antara program dan pengguna. Fungsi `prompt()` digunakan untuk meminta pengguna memasukkan nama, sedangkan `alert()` digunakan untuk menampilkan pesan sapaan berdasarkan nama yang dimasukkan.

### 03. Function dan Operasi Aritmetika

Latihan ini membahas penggunaan function dan operator aritmetika. Operasi yang dipelajari meliputi penjumlahan (`+`), pengurangan (`-`), perkalian (`*`), pembagian (`/`), dan modulus (`%`). Hasil perhitungan ditampilkan melalui Console browser.

### 04. Seleksi Kondisi If-Else

Latihan ini menggunakan struktur percabangan `if-else` untuk menentukan status kelulusan berdasarkan nilai. Program memeriksa kondisi yang telah ditentukan, kemudian menampilkan hasil yang sesuai, seperti lulus atau tidak lulus.

### 05. Seleksi Kondisi Switch

Latihan ini mempelajari struktur `switch` untuk menjalankan perintah berdasarkan pilihan atau nilai tertentu. Setiap pilihan mempunyai hasil yang berbeda, sedangkan bagian `default` digunakan ketika nilai yang dimasukkan tidak sesuai dengan pilihan yang tersedia.

### 06. Form Bilangan Genap atau Ganjil

Latihan ini menerapkan manipulasi DOM untuk menerima angka melalui form HTML. JavaScript memeriksa angka menggunakan operator modulus (`%`). Jika sisa pembagian angka dengan 2 adalah 0, angka termasuk genap; jika tidak, angka termasuk ganjil.

### 07. Mengubah Warna Halaman

Latihan ini menunjukkan penggunaan JavaScript untuk mengubah tampilan halaman web secara langsung. Pengguna dapat menekan tombol yang tersedia untuk mengganti warna latar halaman tanpa perlu memuat ulang halaman.

### 08. DOM dan Checkbox Menu Makanan

Latihan ini menggabungkan checkbox HTML dengan JavaScript untuk menghitung harga menu makanan. Program membaca menu yang dipilih pengguna, menjumlahkan harga setiap menu yang dicentang, dan memperbarui total harga sesuai pilihan tersebut.

### 09. Mini Project — Kalkulator Nilai Mahasiswa

Mini-project ini menerapkan materi HTML dan JavaScript dalam program kalkulator nilai mahasiswa. Pengguna memasukkan nilai tugas, UTS, dan UAS. Program menghitung nilai akhir menggunakan bobot yang telah ditentukan, kemudian menampilkan predikat huruf dan status kelulusan berdasarkan hasil perhitungan.

### 10. Eksperimen Mandiri

Eksperimen mandiri dilakukan untuk memperdalam pemahaman terhadap materi yang telah dipelajari.

1. **Operasi aritmetika dengan Prompt:** menerima dua angka dari pengguna dan menghitung penjumlahan, pengurangan, perkalian, pembagian, serta modulus.
2. **Tabel perkalian:** menggunakan perulangan `for` untuk menampilkan tabel perkalian angka 7 dari 1 sampai 10.
3. **Function cek genap:** membuat function `cekGenap()` untuk memeriksa apakah sebuah angka termasuk bilangan genap.
4. **Validasi form:** memeriksa input nama dan nilai agar sesuai dengan ketentuan yang dibuat.
5. **Penambahan menu makanan:** menambahkan pilihan menu beserta harga dan menghubungkannya dengan perhitungan total.
6. **Sembunyikan dan tampilkan teks:** menggunakan tombol serta manipulasi DOM untuk mengatur apakah teks ditampilkan atau disembunyikan.

## 🛠️ Teknologi dan Tools

- **HTML5** — digunakan untuk membangun struktur halaman web, form, tombol, dan checkbox.
- **JavaScript** — digunakan untuk menjalankan logika program, mengolah input, menghitung data, dan membuat interaksi.
- **Visual Studio Code** — digunakan untuk menulis dan mengedit kode.
- **Google Chrome** — digunakan untuk menjalankan serta menguji halaman web.
- **Developer Tools Console** — digunakan untuk melihat output `console.log()` dan memeriksa hasil program.

## 🚀 Cara Menjalankan Program

1. Buka repository [lab5web](https://github.com/nabilafawwaz57-cell/lab5web).
2. Unduh repository atau buka folder proyek yang sudah tersimpan di komputer.
3. Buka folder proyek menggunakan Visual Studio Code.
4. Pastikan file HTML dan JavaScript berada di lokasi yang sesuai dengan pemanggilan script di HTML.
5. Buka file `index.html` menggunakan Google Chrome.
6. Coba setiap fitur yang tersedia pada halaman web.
7. Untuk melihat output Console, buka menu Chrome → **More tools → Developer tools → Console**.
